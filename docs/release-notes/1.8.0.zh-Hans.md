### Shrinker Pro

- **转换为 WebP、AVIF 或 JPEG XL 绝不会让文件变大。**如果结果比原文件大，就保留原文件。
- **品质为 100 的 AVIF 恢复正常**，适用于 macOS 27。

### Shrinker Studio

- **35 种风格**，包括可用你自己的两种颜色的全新品牌双色调。加星标的风格会排在最上面。
- **缩放控件**位于照片角落，Studio 窗口也可以进入全屏。
- **给照片更多空间**：拖移照片列表的边缘调整宽度，或按 ⌃⌘S 将它收起。分屏分隔条上的手柄只在指针靠近时才显示。
- **玻璃边栏**，如果你喜欢：在设置 ▸ Studio 中开启。
- **按最短边调整大小**，还可以选择 App 启动时进入 Shrinker Pro 还是直接进入 Studio。
- **预览不再卡住**：更新期间切换照片也没问题，切换后预览会刷新的照片会在列表中标出。
- **撰写评论**可从 Shrinker Pro 菜单进入，想告诉其他人 Studio 帮到了你什么，就来写一写。
