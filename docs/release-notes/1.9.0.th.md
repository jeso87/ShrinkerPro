### Shrinker Studio

- **ปรับให้ตรง** ขั้นตอนสูตรใหม่จะปรับเส้นขอบฟ้าที่เอียงให้ตรงโดยอัตโนมัติ และในรูปถ่ายใดก็ได้ “ปรับให้ตรงด้วยมือ…” ให้คุณตั้งมุมเองโดยเทียบกับเส้นตาราง
- **เก็บรูปถ่ายทั้งรูป** สำหรับแสตมป์ ภาพพิมพ์ และทุกอย่างที่ขอบมีความสำคัญ: ไม่มีส่วนใดถูกตัดออก และมุมจะถูกเติมด้วยพื้นหลังหรือสีที่คุณเลือก
- **ครอบตัดตามวัตถุ** Studio จะปรับภาพสแกนให้ตรงแล้วครอบตัดตามแสตมป์ ภาพพิมพ์ หรือการ์ดบนกระจกสแกนเนอร์ โดยมีระยะขอบตั้งแต่ 0 ถึง 10% ฝุ่นและเส้นผมบนกระจกจะไม่ถูกนับรวม
- **“เทียบข้างกัน” วางพอดีข้างแถบด้านข้าง** และคุณซูมออกได้จนแม้แต่ภาพสแกนที่ใหญ่มากก็แสดงได้พอดี
- **แก้ไขแล้ว:** เมื่อเลือก “ทุกรูปถ่าย” ไว้ การลากแถบเลื่อนคุณภาพใน “ดูเหมือนเดิม” จะเปลี่ยนเฉพาะรูปถ่ายที่อยู่ด้านหน้า ตอนนี้จะตั้งสูตรเป็น “กำหนดเอง” ที่คุณภาพนั้น จึงบันทึกไปพร้อมกับสูตร
