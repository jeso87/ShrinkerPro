### 认识 Shrinker Studio

Shrinker Pro 依然免费、不限次数。Studio 是其中的一个可选升级，为那些不止需要快速压缩一下的照片而准备：

- **保存前先比较**：分屏、并排，或用差异视图看清压缩改动过的每一个像素。
- **配方**：调整大小与裁剪、调整画面，加上风格、水印、边框或新名称，然后保存下来，用于任何一批照片。
- **监视文件夹**：放进文件夹的新照片会自动处理完成，即使没有打开任何窗口。

点按工具栏中的 **Studio** 即可开始导览。前 10 次导出可以使用 Studio 的全部工具；购买一次性许可证即可解锁之后的所有导出。
