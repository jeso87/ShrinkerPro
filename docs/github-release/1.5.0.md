Shrinker Pro is now translated into 36 languages, and Settings is two tabs
instead of one column taller than a laptop screen.

## Download

**[ShrinkerPro-1.5.0.dmg](https://github.com/jeso87/ShrinkerPro/releases/download/v1.5.0/ShrinkerPro-1.5.0.dmg)** — 3.7 MB. Open it and drag Shrinker Pro to Applications.

Signed with a Developer ID and notarized by Apple, with the ticket stapled to
the DMG, so it opens by double-clicking: no right-click-Open, no Gatekeeper
warning, no network round trip on first launch.

**Requires macOS 14 Sonoma or later, on an Apple Silicon Mac.** Every Mach-O
in the bundle is arm64 — not "supports Apple Silicon", *only* Apple Silicon —
so it will not run on an Intel Mac at all.

Or from Homebrew:

```
brew install jeso87/tap/shrinker    # the headless `shrinker` command
```

Existing installs are offered this automatically; nothing to do.

## In 36 languages

Arabic, Catalan, Chinese (Simplified, Traditional and Hong Kong), Croatian,
Czech, Danish, Dutch, Finnish, French, German, Greek, Hebrew, Hungarian,
Icelandic, Italian, Japanese, Korean, Norwegian (Bokmål and Nynorsk), Persian,
Polish, Portuguese (Brazil and Portugal), Romanian, Russian, Slovak, Slovenian,
Spanish, Swedish, Thai, Turkish, Ukrainian and Vietnamese.

There is nothing to choose — the app follows the language macOS is set to. The
set matches the 36 the updater itself ships in, so the app and its update
dialog can never be in different languages, and the update notes are
translated too.

Where macOS already has a word for something, the app uses that word rather
than a fresh translation of it: **Reveal in Finder**, **Keep Both**,
**Replace** and the rest were each read out of the system's own shipping
resources. Plural forms and typography were measured per language rather than
assumed — Arabic reaches five plural categories for whole numbers, Polish and
Russian never reach `other` at all, and Czech, Slovak, Polish and Russian take
a non-breaking space after one-letter prepositions where Croatian, Slovenian
and Ukrainian do not.

Arabic, Hebrew and Persian lay the whole window out right to left.

**These are machine translations made against those platform sources, not
native-speaker work.** They have not been reviewed by a speaker of every
language. Corrections are very welcome and are a one-file change —
`translations/<lang>.json` in this repo, one per language.

The headless `shrinker` command stays in English on purpose: its output is
something scripts read, and a message that changes wording with the Mac's
region is a message no script can match on.

## Settings is two tabs

It was over a thousand points tall and had to scroll, which put the Metadata
and General sections below the bottom edge of a laptop screen. It is now
**Output** and **Conversion**, each short enough to need no scrolling at all,
and the window sizes itself to whichever tab is showing — and to the language
it is in, stacking a row whose label and options no longer fit side by side
rather than cutting the text off.

## Fixed

The crop fields hold five digits. They had always been documented as holding
five and never did: anything from `12345` up was silently truncated to an
ellipsis while you typed it. Four digits fit, so `1920` and `3840` never
showed it.

Shrinker Pro's own code is MIT. The app also bundles **gifsicle** (GPL-2.0) and
**pngquant** with **libimagequant** (GPL-3.0-or-later) as executables, plus
BSD/libpng components. `ShrinkerPro-1.5.0-thirdparty-sources.zip` is the
corresponding source for those, published alongside the binaries because the
GPL requires it — not as a courtesy. Full details in
