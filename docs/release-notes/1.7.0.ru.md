### Встречайте Shrinker Studio

Shrinker Pro остаётся бесплатным и без ограничений. Studio — это необязательное
расширение внутри него для фотографий, которым нужно больше, чем быстрое
уменьшение:

- **Сравнивайте перед сохранением:** Split View, рядом или вид «Разница»,
  который показывает каждый пиксель, изменённый сжатием.
- **Рецепты:** измените размер и обрежьте, скорректируйте, добавьте стиль,
  водяной знак, рамку или новые имена, а затем сохраните всё это для любой
  пачки.
- **Отслеживаемые папки:** новые фотографии в папке выходят готовыми, даже когда
  ни одно окно не открыто.

Нажмите **Studio** в панели инструментов, чтобы пройти обзор. Все инструменты
Studio работают для ваших первых 10 экспортов; разовая лицензия снимает это
ограничение.
