### Shrinker Studioのご紹介

Shrinker Proはこれからも無料で、制限なく使えます。Studioはその中に加わるオプションのアップグレードで、手早い圧縮だけでは足りない写真のためのものです。

- **保存する前に比較**：分割表示、並べて表示、そして圧縮で変化したピクセルをすべて見せる差分表示。
- **レシピ**：サイズ変更と切り取り、補正、ルック、透かし、枠線、新しい名前を組み合わせ、どのバッチにも使えるように保存できます。
- **監視フォルダ**：フォルダに入った新しい写真が、ウインドウを開いていなくても仕上がった状態で出てきます。

ツールバーの**Studio**を押すと、ツアーが始まります。最初の10回の書き出しではStudioのすべてのツールを使えます。それ以降は買い切りのライセンスで使えるようになります。
