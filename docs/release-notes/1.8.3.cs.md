### Shrinker Studio

- **Vyberte recept, se kterým Studio začíná.** Nastavení ▸ Studio ▸ Výchozí recept otevře okno Studio s jedním z vašich uložených receptů místo prázdného.
- **Duplex značky si pamatuje vaše barvy.** Nový duplex značky začíná dvěma barvami, které jste vybrali naposledy. „Použít standardní barvy“ vrátí indigovou a broskvovou.
