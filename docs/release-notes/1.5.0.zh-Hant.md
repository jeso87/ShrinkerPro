### Shrinker Pro現在支援36種語言

冰島語、波蘭語、波斯語、葡萄牙語（巴西和葡萄牙）、法語、芬蘭語、德語、丹麥語、土耳其語、泰語、挪威語（博克馬爾和尼諾斯克）、羅馬尼亞語、克羅埃西亞語、荷蘭語、韓語、加泰隆尼亞語、捷克語、希伯來語、西班牙語、希臘語、匈牙利語、中文（簡體、繁體和香港）、日語、瑞典語、斯洛伐克語、斯洛維尼亞語、義大利語、烏克蘭語、越南語、阿拉伯語、俄語。

沒有什麼要選。App跟隨macOS已經設定的語言，而這36種也正是更新對話框本身隨附的語言，所以你不會遇到視窗是一種語言、更新提示卻是另一種語言的情況。

系統裡已經有這個詞的地方，App就沿用系統的詞，而不是重新翻譯一遍。**在Finder中顯示**、**兩者皆保留**、**取代**、**品質**等等，都是從macOS自己的資源裡讀出來的。阿拉伯語、希伯來語和波斯語會把整個視窗從右到左排列。

無介面的`shrinker`指令刻意維持英文：它的輸出是給指令碼讀的，而一則措辭會隨Mac地區設定改變的訊息，是任何指令碼都無法比對的訊息。

### 設定分成兩個標籤頁

視窗高度超過一千點，必須捲動，後設資料和一般這兩個部分因此落到筆記型電腦螢幕的下緣之外。現在它是**輸出**和**轉換**，各自都短到完全不必捲動，視窗也會依照你所在的標籤頁調整自己的大小。

它也會依照所處的語言調整大小。當某一行的標籤和選項並排放不下時，它會把兩者上下排列，而不是悄悄把文字截斷。

### 一些小改動

裁切輸入框能容納五位數。它一直聲稱如此，卻從來沒做到。`12345`以上的數字會在你輸入時被悄悄截斷成一個刪節號。

視窗的最小寬度現在是依照它必須容納的面板量出來的，不再固定為一個剛好適合英文的數值。
