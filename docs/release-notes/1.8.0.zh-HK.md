### Shrinker Pro

- **轉換為WebP、AVIF或JPEG XL絕不會令檔案變大。**如果結果比原檔大，就保留原檔。
- **品質為100的AVIF恢復正常**，適用於macOS 27。
- **新功能**位於Shrinker Pro選單中，顯示最近幾個版本的這些說明。

### Shrinker Studio

- **35種風格**，包括可用你自己兩種顏色的全新品牌雙色調。加了星號的風格會排在最上面。
- **縮放控制**位於相片角落，Studio視窗亦可進入全螢幕。
- **給相片更多空間**：拖移相片列表的邊緣調整闊度，或按⌃⌘S將它收起。分割顯示分隔線上的把手只在指標靠近時才顯示。
- **玻璃側邊欄**，如果你喜歡：在設定 ▸ Studio 中開啟。
- **按最短邊調整大小**，亦可選擇App啟動時進入Shrinker Pro還是直接進入Studio。
- **預覽不再卡住**：更新期間切換相片也沒問題，切換後預覽會重新整理的相片會在列表中標示。
- **撰寫評論**可從Shrinker Pro選單進入，想告訴其他人Studio幫了你什麼，就來寫一寫。
