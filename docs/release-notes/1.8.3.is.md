### Shrinker Studio

- **Veldu uppskriftina sem Studio byrjar með.** Stillingar ▸ Studio ▸ Upphafsuppskrift opnar Studio gluggann með einni af vistuðu uppskriftunum þínum í stað tómrar.
- **Tvítóna vörumerkis man litina þína.** Ný tvítóna vörumerkis byrjar með litunum tveimur sem þú valdir síðast. „Nota staðlaða liti“ setur indigó og ferskjulit aftur.
