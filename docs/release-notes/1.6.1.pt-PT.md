### «⌘O» fica na linha

Com o JPEG XL na lista de formatos por baixo de
**Arraste os ficheiros para aqui**, a linha ficava demasiado comprida para uma
janela nova e «⌘O» passava sozinho para uma linha própria. A lista está agora
mais curta e, onde a linha ainda tiver de quebrar, «ou prima ⌘O» desce todo
junto em vez de deixar «⌘O» isolado.
