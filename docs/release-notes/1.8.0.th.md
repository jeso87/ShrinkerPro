### Shrinker Pro

- **การแปลงเป็น WebP, AVIF หรือ JPEG XL จะไม่ทำให้ไฟล์ใหญ่ขึ้นเลย** หากผลลัพธ์ใหญ่กว่าต้นฉบับ จะเก็บต้นฉบับไว้แทน
- **AVIF คุณภาพ 100 ใช้งานได้อีกครั้ง** บน macOS 27

### Shrinker Studio

- **ลุค 35 แบบ** รวมถึงดูโอโทนแบรนด์ใหม่ในสองสีที่คุณเลือกเอง ลุคที่คุณติดดาวไว้จะอยู่ด้านบนสุด
- **ตัวควบคุมการซูม** ที่มุมของรูป และหน้าต่าง Studio เปิดแบบเต็มหน้าจอได้
- **พื้นที่ให้รูปมากขึ้น:** ลากขอบของรายการรูปเพื่อปรับขนาด หรือพับเก็บด้วย ⌃⌘S แฮนเดิลบนตัวแบ่งของ Split View จะแสดงเมื่อเมาส์อยู่ใกล้ๆ เท่านั้น
- **แถบด้านข้างแบบกระจก** ถ้าชอบ: เปิดได้ในการตั้งค่า ▸ Studio
- **ปรับขนาดตามด้านที่สั้นที่สุด** และเลือกได้ว่าจะให้แอปเปิดใน Shrinker Pro หรือเข้า Studio ทันที
- **ตัวอย่างไม่ค้างอีกต่อไป** เมื่อสลับรูปขณะที่กำลังอัปเดต และรูปที่ตัวอย่างจะรีเฟรชเมื่อสลับไปหาจะมีเครื่องหมายในรายการ
- **เขียนรีวิว** ได้จากเมนู Shrinker Pro ถ้าอยากบอกคนอื่นว่า Studio ช่วยคุณได้อย่างไร
