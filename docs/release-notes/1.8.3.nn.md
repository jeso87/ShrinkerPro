### Shrinker Studio

- **Vel oppskrifta Studio startar med.** Innstillingar ▸ Studio ▸ Startoppskrift opnar Studio-vindauget med ei av dei lagra oppskriftene dine i staden for ei tom.
- **Merkeduotone hugsar fargane dine.** Ein ny merkeduotone startar med dei to fargane du valde sist. «Bruk standardfargar» set indigo og fersken tilbake.
