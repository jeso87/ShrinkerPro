### Shrinker Pro

- **AVIF on macOS 14 and 15.** These systems can open AVIF files but can't
  save them; that needs macOS 26. AVIF is now greyed out in the format menus
  there, with the reason, instead of failing on every file.

### Shrinker Studio

- **AVIF and JPEG XL export again on macOS 14, 15 and 26.** Studio's
  metadata check mistook a brightness value those systems report for
  leftover metadata, and refused the file.
