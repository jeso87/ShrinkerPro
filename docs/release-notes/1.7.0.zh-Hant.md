### 認識Shrinker Studio

Shrinker Pro依然免費、不限次數。Studio是其中的一個選用升級，為那些不只需要快速壓縮一下的照片而準備：

- **儲存前先比較**：分割顯示、並排，或用差異顯示看清壓縮改動過的每一個像素。
- **配方**：調整大小並裁切、調整畫面，加上風格、浮水印、邊框或新名稱，然後儲存起來，套用於任何一批照片。
- **監看檔案夾**：放進檔案夾的新照片會自動處理完成，即使沒有開啟任何視窗。

按一下工具列中的**Studio**即可開始導覽。前10次匯出可以使用Studio的全部工具；購買一次性授權即可解鎖之後的所有匯出。
