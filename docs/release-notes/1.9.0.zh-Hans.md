### Shrinker Studio

- **拉直。** 新的配方步骤会自动拉直倾斜的地平线。在任意照片上，“手动拉直…”可让你对照网格自行设定角度。
- **保留整张照片。** 适用于邮票、冲印照片以及边缘重要的内容：不会裁掉任何部分，四角会以背景或你选取的颜色填充。
- **裁剪到物件。** Studio 会拉直扫描件，并将其裁剪到扫描仪玻璃板上的邮票、冲印照片或卡片，边距可设为 0 到 10%。玻璃上的灰尘和毛发会被忽略。
- **“并排”可在边栏旁完整显示，** 你还可以缩小到连非常大的扫描件也能完整显示。
- **修复：** 选中“所有照片”时，在“看起来一样”中拖移质量滑块只会更改最前面的照片。现在它会将配方设为该质量下的“手动”，因此会随配方一起存储。
