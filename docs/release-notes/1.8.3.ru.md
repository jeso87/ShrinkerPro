### Shrinker Studio

- **Выберите рецепт, с которого начинается Studio.** «Настройки» ▸ Studio ▸ «Начальный рецепт» открывает окно Studio с одним из сохранённых рецептов вместо пустого.
- **Дуотон бренда запоминает ваши цвета.** Новый дуотон бренда начинается с двух последних выбранных цветов. «Стандартные цвета» возвращают индиго и персиковый.
