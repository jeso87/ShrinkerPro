Shrinker Pro reads and writes JPEG XL, and a JPEG converted to it loses
nothing. The app also installs with Homebrew now.

## Download

**[ShrinkerPro-1.6.0.dmg](https://github.com/jeso87/ShrinkerPro/releases/download/v1.6.0/ShrinkerPro-1.6.0.dmg)** — 5.8 MB. Open it and drag Shrinker Pro to Applications.

Signed with a Developer ID and notarized by Apple, with the ticket stapled to
the DMG, so it opens by double-clicking: no right-click-Open, no Gatekeeper
warning, no network round trip on first launch.

**Requires macOS 14 Sonoma or later, on an Apple Silicon Mac.** Every Mach-O
in the bundle is arm64 — not "supports Apple Silicon", *only* Apple Silicon —
so it will not run on an Intel Mac at all.

Or from Homebrew:

```
brew install --cask jeso87/tap/shrinker-pro   # the app
brew install jeso87/tap/shrinker              # the headless `shrinker` command
```

In a `Brewfile`, the app is `tap "jeso87/tap"` and `cask "shrinker-pro"`. The
cask declares `auto_updates`, so the app keeps updating itself through Sparkle
and Homebrew leaves it to. (#7)

Existing installs are offered this automatically; nothing to do.

## JPEG XL, in and out

Drop a `.jxl` file and it is shrunk like any other. JPEG XL is also a new
target: in every format's rule on the **Conversion** tab, the HEIC/HEIF row,
the session bar's **Convert all to**, and `shrinker --to jxl`.

The encoder is libjxl's `cjxl` 0.12.0, built from source as a static arm64
binary like the other helpers. Decoding is macOS's own ImageIO.

## A JPEG converted to JPEG XL loses nothing

The JPEG's own compressed data is carried across rather than decoded and
encoded again, so the file comes out about a fifth smaller — 12.2 MB to 9.8 MB
on a full-size photo — and the original JPEG can be rebuilt from it byte for
byte (`djxl` will do it).

**Quality** does not apply on that path, since there is nothing to choose. A
JPEG that is rotated, resized or cropped on the way is encoded again at the
chosen **Quality** instead. Other sources are encoded at levels matched to
WebP's file sizes on six camera originals, so switching a rule from WebP to
JPEG XL does not quietly change how hard it compresses.

The DMG is 2.2 MB larger than 1.5.0's. That is the encoder.
