### Shrinker Pro

- **AVIF på macOS 14 og 15.** Desse systema kan opne AVIF-filer, men ikkje
  lagre dei; det krev macOS 26. AVIF er no nedtona i formatmenyane der, med
  årsaka, i staden for å mislukkast for kvar fil.

### Shrinker Studio

- **Eksport til AVIF og JPEG XL verkar igjen på macOS 14, 15 og 26.**
  Metadatakontrollen i Studio forveksla ein lysstyrkeverdi som desse systema
  rapporterer, med attverande metadata, og avviste fila.
