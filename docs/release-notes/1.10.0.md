### Shrinker Pro

- **Camera RAW, TIFF, PSD and BMP.** Drop them in like any photo. They're converted to JPEG, or to the format you pick in Settings ▸ Conversion.
- **HEIC and TIFF output**, in the format menu and on the command line.
- **Smaller PNGs.** A lossless pass after the usual compression makes most PNGs a few percent smaller, with every pixel unchanged.
- **Drag a result out** of the list into Finder, Mail or an upload form.
- **Settings ▸ Where ▸ Ask each time** asks for a folder with every drop.

### Shrinker Studio

- **Fit inside.** Resize & crop can keep the whole photo inside its shape, with a white, black, transparent, coloured or blurred background. Print sizes at 300 ppi are in the crop menu.
- **One `<picture>`, several formats.** The Responsive set can also write every size as AVIF, JPEG XL or WebP, and Copy HTML gives a `<source>` for each.
- **Alt text and file names from Apple Intelligence** (macOS 27): Copy HTML can include a description of each photo, and Rename's Description token names files from what they show.
- **Redact finds faces, phone numbers and street addresses.**
- **Change the capture date and place.** Metadata can shift every date (for a camera clock set wrong) or set one, and round the location to about 1 km or set a new one.
- **HEIC and TIFF output.**
- **Watch folders** can notify you when photos are done, and Shrinker Pro can open at login so they keep working.
- **The batch list** has Clear Batch, ⌘A to select every photo and Remove from Studio, and Settings ▸ Studio chooses when the rest of the batch previews.
- **Drag the export summary** into Finder, Mail or an upload form to take every file just written.
