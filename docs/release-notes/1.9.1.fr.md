### Shrinker Studio

- **Netteté devient un masque flou complet.** Intensité jusqu’à 400 %, avec Rayon et Seuil. Le rayon correspond au masque flou d’Affinity : vos réglages Affinity s’appliquent tels quels. L’action Raccourcis les propose aussi.
- **Coins arrondis sans cadre.** Réglez la largeur d’une bordure Arrondi sur 0 % pour arrondir uniquement les coins de la photo.
- **Enregistrer dans ▸ Demander lors de l’exportation.** Choisissez le dossier à chaque exportation.
- **Saisissez la valeur de n’importe quel curseur** dans la fenêtre d’une étape.
