### Shrinker Pro

- **Roter mot venstre og høgre.** Høgreklikk på eit resultat for å rotere det. Det blir laga på nytt frå originalen, så rotering kostar aldri kvalitet.
- **Alle format det les,** står no der du slepper filer.
- **Meir stabil med store bunkar.** Ein sjeldan stans ved komprimering av mange filer samtidig er retta.

### Shrinker Studio

- **Roter og rett opp.** Roter bilete ein kvart eller halv omdreiing, eller spegelvend dei, for heile oppskrifta eller berre dei valde bileta (⌘L og ⌘R), i tillegg til å rette opp horisonten.
- **Snu kvart foto rett veg.** Andlet og tekst avgjer kva som er opp. Eit foto der det ikkje er tydeleg, blir ståande som det er. «Snu rett veg» gjer det for markeringa.
- **Fjern bakgrunn** (macOS 15 eller nyare). Motivet blir frilagt på Macen og lagt på kvitt, svart, ein farge eller gjennomsikt, med skugge om du vil. Ein kvit bakgrunn held seg nøyaktig 255, 255, 255 i JPEG og PNG.
- **Gjer berre bakgrunnen kvit**, for produkt som alt er fotograferte på nesten kvitt: Produktet blir aldri rørt.
- **Sjekk for eit mål.** 21 marknadsplassar, sosiale nettverk, fotoklubbar, biletbyrå og utskriftsstorleikar. Start ei oppskrift frå eit mål, og kvar fil blir merkt som bestått, åtvaring eller ikkje bestått etter dei publiserte reglane.
- **Ramm inn motivet** så det fyller ein fast del av biletet, og **tilpass til** ein boks som ein klubbprojektors 1920 × 1080.
- **Avrunda rammer** kan òg avrundast på utsida, med gjennomsiktige hjørne.
- **Nye beskjeringar for sosiale medium:** Instagram-rutenett, Threads, TikTok-foto og Facebook kvadratisk. Facebook-innlegg er no 1080 × 1350.
- **Snarvegar:** Roter bilete og Fjern bakgrunn.
