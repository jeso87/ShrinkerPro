### พบกับ Shrinker Studio

Shrinker Pro ยังคงใช้ได้ฟรีและไม่จำกัด Studio คือการอัปเกรดเสริมที่อยู่ในแอป สำหรับรูปถ่ายที่ต้องการมากกว่าการบีบอัดแบบรวดเร็ว:

- **เปรียบเทียบก่อนบันทึก:** Split View เทียบข้างกัน หรือมุมมองส่วนต่างที่แสดงทุกพิกเซลที่การบีบอัดเปลี่ยนไป
- **สูตร:** ปรับขนาดและครอบตัด ปรับแต่ง ใส่ลุค ลายน้ำ ขอบ หรือชื่อใหม่ แล้วบันทึกไว้ใช้กับชุดภาพใดก็ได้
- **โฟลเดอร์เฝ้าดู:** รูปถ่ายใหม่ในโฟลเดอร์จะออกมาเสร็จเรียบร้อย แม้ไม่มีหน้าต่างใดเปิดอยู่

กด **Studio** ในแถบเครื่องมือเพื่อชมทัวร์แนะนำ เครื่องมือทุกอย่างของ Studio ใช้ได้กับการส่งออก 10 ครั้งแรกของคุณ และใบอนุญาตแบบจ่ายครั้งเดียวจะปลดล็อกส่วนที่เหลือ

### การแก้ไขอื่นๆ

- หน้าต่างหลักจะเปิดในขนาดที่ถูกต้องเมื่อเปิดแอป
- ปุ่มการตั้งค่ามีชื่อแล้ว VoiceOver จึงอ่านได้ และแสดงในเมนูรายการเพิ่มเติมของแถบเครื่องมือ
