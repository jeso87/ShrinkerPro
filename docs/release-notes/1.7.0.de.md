### Das ist Shrinker Studio

Shrinker Pro bleibt kostenlos und unbegrenzt. Studio ist ein optionales Upgrade
darin, für Fotos, die mehr brauchen als schnelles Verkleinern:

- **Vergleichen vor dem Sichern:** Trennansicht, nebeneinander oder eine
  Differenz-Ansicht, die jedes Pixel zeigt, das die Komprimierung verändert hat.
- **Rezepte:** Größe ändern und zuschneiden, anpassen, einen Look, ein
  Wasserzeichen, einen Rahmen oder neue Namen hinzufügen – und das Ganze für
  jeden Stapel sichern.
- **Überwachungsordner:** Neue Fotos in einem Ordner kommen fertig heraus, auch
  wenn kein Fenster geöffnet ist.

Klicke in der Symbolleiste auf **Studio**, um eine Tour zu starten. Für deine
ersten 10 Exporte funktioniert jedes Studio-Werkzeug; eine einmalige Lizenz
schaltet den Rest frei.
