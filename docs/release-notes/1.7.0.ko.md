### Shrinker Studio를 소개합니다

Shrinker Pro는 앞으로도 무료이며 제한이 없습니다. Studio는 그 안에 있는 선택형 업그레이드로, 빠른 압축만으로는 부족한 사진을 위한 것입니다.

- **저장하기 전에 비교:** 분할 보기, 나란히 보기, 또는 압축으로 바뀐 모든 픽셀을 보여 주는 차이 보기.
- **레시피:** 크기 조절과 자르기, 보정, 룩, 워터마크, 테두리, 새 이름을 더한 뒤 어떤 일괄 작업에도 쓸 수 있도록 저장합니다.
- **감시 폴더:** 폴더에 들어온 새 사진이 윈도우를 열어 두지 않아도 완성된 상태로 나옵니다.

도구 막대에서 **Studio**를 누르면 둘러보기가 시작됩니다. 처음 10회 내보내기까지는 Studio의 모든 도구를 사용할 수 있으며, 1회 결제 라이선스로 나머지가 잠금 해제됩니다.

### 그 밖의 수정 사항

- 실행 시 메인 윈도우가 원래 크기로 열립니다.
- 설정 버튼에 이름이 생겨 VoiceOver가 읽어 주고 오버플로 메뉴에도 표시됩니다.
